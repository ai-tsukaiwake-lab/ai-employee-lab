テーマを入力してGitHub Actionsへ移動。実際の実行はGitHubで本人が確定します。公開ページにはGitHubの認証情報を入力しません。

入力文字数：0/240

② GitHub Actionsを開く
  1. 依頼テーマを入力し、コピー内容を確認する。
  2. 「GitHub Actionsを開く」を押してログイン済みのGitHubへ移動。
  3. 緑色の「Run workflow」を押し、ブランチ main を確認。
  4. テーマの入力欄にコピーした文章を貼り付け、もう一度「Run workflow」を押す。
  5. 実行成功後、ホームの「公開進捗を更新」で最新状況を確認。下書きや監査全文は引き続き bundle.json を端末内で読み込む。
安全上の制限：この画面自体はGitHub Actionsを起動しません。GitHubトークンやGemini APIキーを入力・保存・送信しません。承認やX投稿も行いません。
